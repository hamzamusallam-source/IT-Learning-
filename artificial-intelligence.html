Artificial Intelligence

From the basic ideas behind AI to generative models, RAG and agents — and how to run AI responsibly inside an organisation.

Path 05Level: Beginner → Mid8 topics≈ 7 weeks

Topic 1AI Fundamentals

Artificial Intelligence is the field of building systems that perform tasks that normally need human intelligence: understanding language, recognising images, predicting outcomes and making decisions.

  • AI is the broad goal; machine learning is the main way we achieve it today.
  • Narrow AI does one task well — all AI in use today is narrow.
  • General AI (AGI) — human-level ability across tasks — is still theoretical.
  • Good data matters more than clever algorithms.

Topic 2Machine Learning

Machine learning systems learn patterns from data instead of following hand-written rules.

  • Supervised: learn from labelled examples (spam / not spam).
  • Unsupervised: find structure in unlabelled data (customer groups).
  • Reinforcement: learn by trial, reward and penalty.
  • Split data into training and test sets to measure real accuracy.

Topic 3Generative AI

Generative AI creates new content — text, images, code, audio — rather than only classifying or predicting.

  • Built on deep neural networks trained on very large datasets.
  • Use cases: drafting, summarising, coding help, search, design.
  • Outputs can be confident and wrong, so review them.
  • Data privacy and intellectual property need clear policies.

Topic 4LLMs

Large Language Models predict the next piece of text, one token at a time. At scale, this produces surprisingly capable assistants.

  • Text is split into tokens; the context window limits how much fits.
  • Pre-training on broad text, then fine-tuning for behaviour.
  • They don't “look things up” unless connected to tools or data.
  • Temperature controls how creative or predictable answers are.

Topic 5Prompt Engineering

Clear instructions get better results. Prompting is the skill of explaining a task well to a model.

  • Give context, the goal, and the format you want.
  • Show examples of good output.
  • Break complex tasks into steps.
  • Test prompts on several inputs, not just one.

Topic 6RAG

Retrieval-Augmented Generation lets a model answer questions using your own documents.

  • Documents are split into chunks and turned into embeddings.
  • A vector search finds the passages most relevant to the question.
  • Those passages are given to the LLM as context.
  • The answer can cite its sources — and stays up to date without retraining.

Topic 7AI Agents

An agent is an AI system that can plan steps and use tools — search, APIs, code — to complete a task, not just answer a question.

  • Loop: plan → act with a tool → observe → continue.
  • Tools give agents real capabilities, and real risks.
  • Limit permissions and keep a human approval step for important actions.
  • Log every action for review.

Topic 8MLOps

MLOps brings DevOps discipline to machine learning so models can be deployed and maintained reliably.

  • Version data, code and models together.
  • Automated training, testing and deployment pipelines.
  • Monitor for drift: real-world data changes over time.
  • Governance: who approved this model, and on what data?
