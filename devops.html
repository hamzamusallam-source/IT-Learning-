DevOps & Automation

Shipping changes quickly and safely by bringing development and operations together, and automating everything that repeats.

Path 09Level: Mid8 topics≈ 6 weeks

Topic 1DevOps Culture

DevOps is first a way of working: shared ownership between the people who build and the people who run.

  • Small, frequent changes instead of big risky releases.
  • Blameless post-incident reviews.
  • Measure: deployment frequency, lead time, failure rate, recovery time.
  • Automate the boring, repeatable work.

Topic 2Version Control

Every change to code and configuration is tracked, reviewed and reversible.

  • Git: commits, branches, merges.
  • Pull requests and code review.
  • A simple branching strategy everyone follows.
  • Keep infrastructure and configuration in Git too.

Topic 3CI/CD

Continuous Integration and Continuous Delivery automate building, testing and releasing.

  • CI: every change is built and tested automatically.
  • CD: every passing build can be released at the push of a button.
  • Pipelines as code.
  • Fast feedback: fail early, fix early.

Topic 4Containers

Containers package an application with everything it needs, so it runs the same everywhere.

  • Images are built from a simple definition file.
  • Lighter and faster to start than virtual machines.
  • Registries store and version images.
  • Scan images for vulnerabilities.

Topic 5Orchestration

Orchestration runs many containers across many servers reliably.

  • Kubernetes is the common standard.
  • Pods, deployments and services.
  • Self-healing, scaling and rolling updates.
  • Start simple; managed services remove a lot of work.

Topic 6Infrastructure as Code

Servers, networks and cloud resources defined in files instead of clicked together.

  • Repeatable environments from the same code.
  • Review infrastructure changes like code changes.
  • Declarative tools describe the desired end state.
  • Detect and correct drift.

Topic 7Scripting

Small scripts remove hours of manual work.

  • PowerShell for Windows environments.
  • Bash for Linux.
  • Python for anything more complex.
  • Make scripts safe to run twice.

Topic 8Observability

Understanding what a system is doing from the outside, so problems are found quickly.

  • Metrics, logs and traces.
  • Dashboards for health; alerts for action.
  • Service level objectives (SLOs).
  • Alert on symptoms users feel, not every small spike.
