IT Fundamentals & Infrastructure

How computers, servers and operating systems work, how they are virtualized and stored, and how to troubleshoot them calmly and methodically.

Path 01Level: Beginner8 topics≈ 5 weeks

Topic 1Hardware & Components

Every computer, from a laptop to a data-center server, is built from the same core parts. Knowing what each one does makes upgrades and fault-finding far easier.

  • CPU: executes instructions; cores and clock speed set its capacity.
  • RAM: fast, temporary working memory, cleared on power-off.
  • Storage: HDDs and SSDs keep data permanently.
  • Motherboard, power supply and network card connect everything together.

Topic 2Operating Systems

The operating system sits between the hardware and the applications. It manages memory, processes, files, devices and users.

  • Desktop and server editions of Windows and Linux.
  • Processes, services and scheduling.
  • File systems, permissions and user accounts.
  • Updates and patching as a routine, not an emergency.

Topic 3Server Administration

A server provides a service to many users at once — files, email, websites, databases. Administering it means keeping it available, secure and up to date.

  • Installing and hardening a server.
  • Managing roles, services and scheduled tasks.
  • Monitoring CPU, memory, disk and logs.
  • Documenting every change you make.

Topic 4Directory Services

A directory service is the central list of users, computers and groups in an organisation, and the rules that apply to them.

  • Single sign-on: one account for many systems.
  • Groups and policies to apply settings at scale.
  • Domain controllers and replication.
  • Joining computers and users to the domain.

Topic 5Virtualization

Virtualization runs many virtual machines on one physical server. A hypervisor shares the hardware between them while keeping each one isolated.

  • Type 1 hypervisors run directly on the hardware — the norm in data centers.
  • Snapshots, cloning and templates speed up delivery.
  • Live migration moves running VMs between hosts.
  • Containers are a lighter alternative for applications.

Topic 6Storage (SAN / NAS)

Enterprise storage is shared over the network instead of living inside each server.

  • NAS shares files over the network (SMB, NFS).
  • SAN provides block storage over a dedicated network (Fibre Channel, iSCSI).
  • RAID protects against disk failure — it is not a backup.
  • Tiering puts hot data on fast disks and cold data on cheap ones.

Topic 7Data Center Basics

A data center is the physical home of servers, storage and network equipment. Its design is about keeping that equipment powered, cool and secure.

  • Redundant power: UPS units and generators.
  • Cooling and hot/cold aisle layout.
  • Racks, cabling and labelling standards.
  • Physical access control and monitoring.

Topic 8Troubleshooting

Good troubleshooting is a method, not luck. Work from symptoms to cause one step at a time.

  • Define the problem and when it started.
  • Gather information: logs, recent changes, who is affected.
  • Form a hypothesis, test it, change one thing at a time.
  • Fix, verify, then document what you learned.
